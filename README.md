# homebrew-tap

The Homebrew tap for [TBD — To be downloaded](https://github.com/eliorpom-cmd/to-be-downloaded),
a native macOS downloader built on yt-dlp.

```bash
brew install --cask eliorpom-cmd/tap/to-be-downloaded
```

That is the whole command. Since 1.2.0 the app is signed with a Developer ID
certificate and notarized by Apple, so macOS opens it without a warning.
Versions 1.0 and 1.1 were not notarized and needed a second `xattr` line; it is
no longer needed, and an app installed back then updates itself.

The app updates itself from signed GitHub releases, so `brew upgrade` is a
fallback rather than the usual path. The cask is regenerated by the app
repository's `scripts/release.sh` on every release and copied here.

Everything else — what the app does, its limits, how to build it — lives in the
[app repository](https://github.com/eliorpom-cmd/to-be-downloaded).
