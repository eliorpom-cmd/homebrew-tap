# homebrew-tap

Homebrew tap for the Mac apps and tools of [eliorpom-cmd](https://github.com/eliorpom-cmd). Every app is signed
with a Developer ID and notarized by Apple, so macOS opens it without a warning.

```bash
brew tap eliorpom-cmd/tap
```

## Apps

| Install | What it does |
| --- | --- |
| `brew install --cask eliorpom-cmd/tap/to-be-downloaded` | [TBD](https://github.com/eliorpom-cmd/to-be-downloaded): downloads YouTube video and audio, with a web remote on your network |
| `brew install --cask eliorpom-cmd/tap/macfin` | [Macfin](https://github.com/eliorpom-cmd/macfin): the movies and TV shows of a Jellyfin server, in a native app |
| `brew install --cask eliorpom-cmd/tap/lumac` | [Lumac](https://github.com/eliorpom-cmd/lumac): sleeps a MacBook when its lid closes with an external display connected |
| `brew install --cask eliorpom-cmd/tap/claude-bounce` | [Claude Bounce](https://github.com/eliorpom-cmd/claude-bounce): bounces your editor's Dock icon when Claude Code finishes |

## Chrome extensions

Each one comes with a small program on your Mac. After installing, run the setup command it prints, then load the
extension in `chrome://extensions` (Developer mode → Load unpacked).

| Install | What it does |
| --- | --- |
| `brew install eliorpom-cmd/tap/m3u8-sniffer` | [M3U8 Sniffer](https://github.com/eliorpom-cmd/m3u8-sniffer): finds the video playing in a tab and downloads it (setup: `m3u8-sniffer-setup`) |
| `brew install eliorpom-cmd/tap/arsene` | [Arsène](https://github.com/eliorpom-cmd/arsene): pseudonymises French text before it reaches ChatGPT or Claude (setup: `arsene-setup`) |

TBD updates itself from signed GitHub releases; its cask is regenerated by the app repository's
`scripts/release.sh`. The other entries are updated by hand at each release (version and `sha256`).
